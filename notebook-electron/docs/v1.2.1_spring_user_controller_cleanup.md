# v1.2.1 Spring 遗留用户控制器清理设计

## 背景

Spring Boot 版本早期通过 `UserController` 暴露 `/api/users/**`，用于学习 JPA CRUD。
后续已经由 `AuthController` 和 `AuthService` 接管注册、登录与 BCrypt 密码处理，正式前端
及笔记本、文档业务均未调用旧接口。

旧控制器仍允许任意已登录用户列出或删除其他用户，并可绕过 `AuthService` 直接保存
未加密密码，因此不应继续保留。

## 变更范围

1. 删除 `UserController`，不再暴露 `/api/users/**`。
2. 删除 `api.http` 中 Day 11 对旧用户 CRUD 接口的手工请求。
3. 保留 `User`、`UserRepository`、`AuthController` 和 `AuthService`，注册登录流程不变。

## 验证标准

- 正式源码和前端不存在对 `/api/users/**` 的调用。
- Java 主源码能够正常编译。
- `/api/auth/register` 与 `/api/auth/login` 所依赖的用户持久化组件仍然存在。
