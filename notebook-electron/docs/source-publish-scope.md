# 源码提交范围与评测资料生成

本次源码提交包含 Web/Electron 运行代码、自动化测试、对应规范和评测程序。面试架构图及其视觉检查文件是个人演示资料，不属于软件运行代码。在线评测报告留在本地，避免将多次运行的大体积明细加入源码仓库。

评测的 `eval/cases.json` 和 `eval/manifest.json` 是固定题目与文档定义，随评测程序提交。`eval/fixtures/` 下的 TXT、Markdown、DOCX、PDF 和边界样本由 `eval/build-corpus.py` 再生，全部忽略。生成脚本必须核对生成的题目与清单是否等于已提交的固定定义；不一致时失败，不静默改变验收集。

默认 `npm test` 只读取已提交的题目定义。损坏 PDF 由测试创建在临时目录并在结束后清理。生成脚本提供无需可选依赖的 `--verify-definitions` 检查；在线文档解析评测先安装文档生成依赖、生成本地样本，再显式运行。UI 冒烟检查独立创建损坏样本；不能把缺少样本误报成模型或检索失败。
