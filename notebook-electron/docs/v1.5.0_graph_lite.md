# v1.5.0 Graph Lite 概念图设计与实现记录

## 目标

在不引入图数据库、不改变普通 RAG 与整理 Agent 行为的前提下，为每个笔记本提供可手动生成、可追溯到原文证据的轻量概念图。首版只负责浏览、筛选、搜索和跳转证据，不参与问答上下文或 Agent 工具。

## 数据与生命周期

数据库从 v3 迁移到 v4。`graph_builds` 记录一次构建的状态、输入指纹、模型和错误；`graph_entities` 与 `graph_relations` 保存白名单类型；`graph_evidence` 将实体/关系连接到文档、分块和字符区间。所有记录通过笔记本外键级联删除。

构建结果先留在内存，所有批次成功后在一个事务内删除并替换该笔记本的旧图谱。中止、失败或超限不会清空旧图谱。文档新建/删除会把现有图谱置为 `stale`，启动时把遗留 `building` 标记为 `interrupted`。

## 抽取约束

- 每批同一文档内的相邻分块最多约 6000 Token，顺序调用 DeepSeek；单次最多 100 篇文档、100 万字符、100 批。超出文档数或字符数时预览不会先执行昂贵分词。
- 只接受预定义实体和关系类型，Zod 严格校验 JSON；非法 JSON最多纠正一次。
- 文档内容始终是不可信数据，提示词禁止执行其中的指令。
- 实体名称执行 NFKC、空白折叠和英文小写归一化；仅合并模型明确声明的别名。
- 实体和关系必须带可在原文分块中精确匹配的证据片段，置信度小于 0.65 的结果丢弃。

## IPC 与 UI

主进程暴露估算、读取、构建和中止通道，事件固定为 `status`、`progress`、`usage`、`completed`、`aborted`、`error` 并带有 `requestId`。笔记本标题区域提供“概念图”按钮；空状态先展示统计和模型调用次数，用户确认后开始。图谱采用本地 SVG，支持筛选、搜索、拖动、缩放，点击节点显示来源证据并跳转文档。

## 测试与安全

离线测试覆盖 v3→v4 迁移、级联删除、stale/中断状态、跨笔记本隔离、结构化输出校验、原文字符区间、别名与同名不同类型实体、失败回滚、不同 requestId 事件、并发与中止。界面中所有模型字段先做 HTML 转义，再写入 Inspector。默认测试不访问网络；在线测试必须显式设置 `RUN_ONLINE_GRAPH_TESTS=1`，并使用三篇独立文档验证每篇资料都产生可精确回映的证据。
