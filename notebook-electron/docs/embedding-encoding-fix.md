# Embedding 编码兼容修复

直接捕获同一请求的HTTP响应与SDK结果：默认请求encoding_format=base64时，智谱返回2048维float数组（范数约1），SDK误解码得到512维全零；显式float时，SDK保留2048维非零数据。因此前次“服务返回全零”的判断不准确，全零产生于客户端转换。

查询与批量统一使用requestEmbeddings：显式float，校验数量、唯一连续索引、有限数值、非零范数和批次内一致维度。非法响应抛错，不让索引标记ready。批量失败不替换旧索引；查询失败沿用显式BM25降级。

启动时发现已存储的无效向量，将所属文档标记stale，保留文件，不自动上传用户资料或自动批量调用服务。用户可使用已有重建入口。独立测试库自动重新索引，用真实向量测试同义改写的稠密检索（不依靠BM25），再跑混合检索验收。

测试：使用当前安装SDK加伪HTTP响应重现默认编码错误并验证修复；数量/索引/NaN/全零/维度异常必须拒绝；真实请求记录维度、范数与检索排名，不记录密钥。
