# v1.2.6 文档提取与文本清洗单元测试设计

## 目标

通过 `DocumentExtractService.extractText()` 的公开入口验证文档类型分发和文本清洗规则，
不直接测试私有方法，保证测试关注外部行为而非内部实现。

## 测试范围

1. TXT 文本去除控制字符、行首尾空白并规整连续空行。
2. Markdown 后缀不区分大小写。
3. 重复出现 3 次的页眉或页脚被移除。
4. 空格占比超过阈值的水印行被移除。
5. 内存中构造的 DOCX 能按段落提取文本。
6. 不支持的扩展名抛出明确异常。
7. 缺少原始文件名时抛出明确异常。

## 测试方式

- 使用 Spring `MockMultipartFile` 在内存中模拟上传文件。
- DOCX 使用 Apache POI 在内存中生成，不读取磁盘文件。
- 不启动 Spring、不连接数据库、不调用 AI API。

## 验证

运行 `./mvnw test`，原有 12 条测试和新增 7 条测试应全部通过。
