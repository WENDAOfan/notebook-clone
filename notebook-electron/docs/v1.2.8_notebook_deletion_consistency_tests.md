# v1.2.8 笔记本删除与向量清理一致性测试设计

## 目标

确保删除笔记本时，不只级联删除数据库中的文档，还会在文档仍可查询时逐个清理对应
向量分块，避免 `vector-store.json` 中残留孤儿数据。

## 测试范围

1. 删除包含多个文档的本人笔记本时，查询全部文档 ID。
2. 对每个文档调用 `DocumentChunkService.deleteDocumentChunks()`。
3. 向量清理完成后再清空聊天历史并删除笔记本数据库记录。
4. 空笔记本不调用向量清理，但仍正常清理历史和删除笔记本。

## 测试方式

- 使用真实 JWT 安全链验证当前用户身份。
- Repository 和 Service 使用 Mockito Mock，不操作真实数据库或向量文件。
- 使用 Mockito `InOrder` 验证清理与删除的调用顺序。

## 验证

先运行测试确认当前实现缺少向量清理，再修复 Controller，最终全部测试通过。
