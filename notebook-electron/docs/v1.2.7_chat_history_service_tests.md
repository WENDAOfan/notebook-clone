# v1.2.7 对话历史服务单元测试设计

## 目标

验证对话历史按用户与资源隔离、消息角色转换、单轮保存、超长历史截断和定时清理规则。

## 测试范围

1. 文档和笔记本会话 ID 同时包含资源 ID 与用户 ID，不同用户不会共用会话。
2. 数据库消息按原顺序转换为 Spring AI 的 UserMessage/AssistantMessage。
3. 保存一轮对话时先保存用户问题，再保存 AI 回答，且元数据一致。
4. 历史超过 2000 条时只删除最旧的溢出消息。
5. 清空文档或笔记本历史时必须同时携带资源 ID 和用户 ID。
6. 定时清理使用约 7 天前作为过期截止时间。

## 测试方式

- 直接创建 `ChatHistoryService`，不启动 Spring。
- `ChatMessageRepository` 使用 Mockito Mock，不连接数据库。
- 使用 ArgumentCaptor 检查实际保存的消息和实际传入的过期时间。

## 验证

运行 `./mvnw test`，预计共 25 条测试全部通过。
