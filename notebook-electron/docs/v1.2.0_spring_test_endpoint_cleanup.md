# v1.2.0 Spring 调试接口清理设计

## 背景

Spring Boot 版本保留了开发阶段使用的 `TestController`、`TestAiController` 和
`ChunkTestController`。其中 `/test/**` 被匿名放行，会暴露模型调用和未按用户隔离的
向量检索能力；`/api/test/**` 虽然需要登录，但不属于正式业务接口。

## 变更范围

1. 删除上述 3 个调试控制器。
2. 从 `SecurityConfig` 删除 `/test/**` 的 `permitAll` 规则。
3. 从 README 和 `api.http` 删除对应调试端点及示例。
4. 保留正式的 `/api/auth/**`、`/api/notebooks/**`、`/api/documents/**` 接口。

## 安全效果

- 未登录请求不再能够直接调用大模型或触发向量化任务。
- 不再提供跨用户、无过滤的向量搜索调试入口。
- 生产接口清单与实际代码保持一致。

## 验证标准

- 源码中不存在 3 个调试控制器及 `/test/**` 放行规则。
- README 与 `api.http` 不再声明或调用这些接口。
- 主业务控制器与服务代码不发生改动。
