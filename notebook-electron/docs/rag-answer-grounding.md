# 回答事实边界（第二轮）

针对模型把保修期限扩展为免费维修承诺的问题，只修改文档问答系统规则，不修改普通聊天、检索算法或添加额外模型调用。

规则独立为 answer-policy.js，共享于单文档和笔记本问答。要求区分问题假设和原文事实，保留范围/条件/概率用词；先回答明确事实，再指出不能确认的部分。只有明确写出的免费、全部、保证、无条件承诺才能肯定。

增加12道新测试：保修、退货运费、部件范围、到账保证、服务费用、培训资格，各含缺少承诺与明确承诺的正反例。在线测试使用真实生产索引与问答入口、独立临时数据库，不修改前轮验收语料及报告。先冻结题目再运行；按答案与实际引用逐题复核，不能只用关键词匹配宣称语义通过。

离线测试验证规则仅进入文档模式，并覆盖工具后的最终回答仍携带规则。在线失败如实记录，本轮不反复针对新题调提示。

新题暴露额外检索问题：当前服务探针返回512维全零向量；单文档BM25有效匹配得分小于1会误拒答。补充向量有效性检查和显式BM25降级警告；关键词分支允许至少两个不同查询词命中，不再依赖跨语料不可比的固定分数作为唯一词法门槛。此次结果必须标注BM25降级，不能视为向量检索验收；不更换模型服务。
