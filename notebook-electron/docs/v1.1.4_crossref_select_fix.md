# v1.1.4 - 修复 Crossref 学术文献检索 API 字段验证失败 (HTTP 400)

## 1. 问题现象与排查

在联网研究与学术文献检索模块中，调用 `CrossrefProvider.search({ query, ... })` 时发生网络请求异常：

```text
Crossref 检索失败: 网络请求失败（HTTP 400）
```

进一步捕获 Crossref 官方 API 响应体定位根因：

```json
{
  "status": "failed",
  "message-type": "validation-failure",
  "message": [
    {
      "type": "select-not-available",
      "value": "language",
      "message": "Select 'language' specified but there is no such select for this route."
    }
  ]
}
```

---

## 2. 根因分析

Crossref API 的 `/works` 路由允许使用 `select` 查询参数指定返回的数据字段列表以精简 Payload。然而，Crossref 官方支持的 `select` 白名单为：

> `abstract, URL, resource, member, posted, score, created, degree, update-policy, short-title, license, ISSN, container-title, issued, update-to, issue, prefix, approved, indexed, article-number, clinical-trial-number, accepted, author, group-title, DOI, is-referenced-by-count, updated-by, event, chair, standards-body, original-title, funder, translator, published, archive, published-print, alternative-id, subject, subtitle, published-online, publisher-location, content-domain, reference, title, link, type, publisher, volume, references-count, ISBN, issn-type, assertion, deposited, page, contributor, content-created, short-container-title, relation, editor`

其中**不包含 `language`**。在原代码中：

```javascript
endpoint.searchParams.set('select', 'DOI,title,author,published,URL,abstract,language,license,score,type');
```

由于显式指定了未支持的 `language` 字段，Crossref 官方网关直接拒绝处理请求并返回 `HTTP 400 Validation Failure`，导致任何学术检索均无法从 Crossref 获取候选文献。

---

## 3. 修复方案设计

1. **精简投影字段**：从 `select` 参数中移除 `language`，保留合法的 9 个字段：
   `'DOI,title,author,published,URL,abstract,license,score,type'`
2. **回退兜底**：在构造归一化候选对象时，`language` 字段默认采用函数入参提供的 `language`（如 `'en'` 或 `'zh'`），保证数据契约完整性：
   ```javascript
   language: item.language || language,
   ```

---

## 4. 验证方式

1. 单元测试回归：`npm test` 保证全量 39 项离线单元测试通过。
2. 在线接口验证：调用真实 Crossref 接口检索 "Agentic RAG" 文献，验证返回 HTTP 200 与有效候选对象。
