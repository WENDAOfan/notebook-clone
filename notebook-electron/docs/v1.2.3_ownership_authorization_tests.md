# v1.2.3 数据归属与防越权自动化测试设计

## 目标

验证已登录用户只能访问或修改归属于自己的笔记本和文档。测试使用真实 JWT 安全链，
但将 Repository 与业务 Service 替换为 Mock，不连接真实数据库或 AI 服务。

## 测试场景

1. Alice 不能删除不属于自己的笔记本，且底层删除方法不得被调用。
2. Alice 不能读取不属于自己的文档。
3. Alice 不能列出不属于自己的笔记本中的文档，且文档查询不得执行。
4. Alice 可以读取属于自己的文档，避免权限规则误伤正常请求。

## 判断标准

当前项目使用统一 `Result` 响应体，因此业务拒绝暂时表现为 HTTP 200 + `code=400`。
测试除检查响应外，还使用 Mockito 验证越权场景下没有执行删除或数据查询。

后续可将“无权访问”改造为标准 HTTP 403/404；本轮先锁定现有业务安全边界。

## 验证命令

```bash
./mvnw test
```

预期认证安全测试与归属测试全部通过。
