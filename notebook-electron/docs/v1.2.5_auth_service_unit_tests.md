# v1.2.5 AuthService 单元测试设计

## 目标

为认证业务服务补充纯单元测试，验证用户注册和登录的核心密码安全规则。

## 测试范围

1. 注册时保存的密码必须是 BCrypt 密文，且能够与原始密码匹配。
2. 用户名已存在时拒绝注册，并且不得调用保存方法。
3. 用户名和密码正确时登录成功。
4. 密码错误时登录失败，且对外返回统一错误信息。

## 测试方式

- 直接创建 `AuthService`，不启动 Spring 容器。
- 使用真实 `BCryptPasswordEncoder` 验证加密行为。
- 使用 Mockito 模拟 `UserRepository`，不连接数据库。
- 使用 JUnit 断言返回值、异常和 Repository 调用情况。

## 验证

运行 `./mvnw test`，原有 8 条安全测试与新增 4 条单元测试应全部通过。
