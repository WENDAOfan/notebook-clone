# 桌面 RAG 正确性与真实验收

2026-10-03 最终检索改进及门槛证据见 [retrieval-delivery.md](retrieval-delivery.md)。基础改进默认启用；旧重排协议因长文问答P95增幅41.5%超限而关闭过，紧凑编号分组协议在校准与独立新资料重新过门槛后才接入桌面默认。DeepSeek就绪时每题最多一次、8秒超时回退；配置 `retrieval.rerank=false` 可关闭，整理 Agent 不启用。库及离线测试仍默认关闭。原基础流程不变，下文型号硬过滤及“实验未启用”为历史过程。

实施顺序：解析失败不入库；仅检索 ready 且内容哈希、模型一致的索引；删除全文兜底；修复工具收尾；累计证据预算及来源诊断；真实评测。

笔记本允许部分就绪，必须显示被排除文档。普通聊天不检查索引。沿用 IPC 与 SQLite 状态，不修改 Java 端。

问答最多三个工具轮次加一次禁用工具的最终回答，最多六次检索，180 秒总超时；无效工具必须返回结果；空回答不得成功入历史。证据累计预算 8000 token，包含包装，重复片段不重复添加。

真实验收使用独立临时库、八份虚构资料和固定划分的 40 题。校准集与验收集各 20 题；禁止用验收集调参。Recall@5 >= .85，MRR >= .80，有答案题至少 14/16 正确且证据支持，无答案 4/4 拒答，P95 <= 60 秒。配置不足标记 BLOCKED，未运行标记 NOT_RUN。

重排是条件实验，不默认引入：只有校准集 MRR 提升 .05、召回及拒答不下降且 P95 增幅 <= 30% 才启用。真实报告记录原始回答与证据，格式校验不能代替事实核对。

校准发现相似型号混排。新增 exactIdentifiers 策略：查询含字母和数字混合的完整标识符、且候选确有该标识符时，仅保留精确匹配的候选；未匹配则保留原候选，避免缩写差异导致空检索。校准候选回放 MRR 从 .59375 到 .85，仍需真实复测。不使用验收题调参。

2026-10-03：上述型号硬过滤现仅保留为 `legacy` 评测对照。它会误删省略型号的预算、合同片段；当前生产检索采用完整短语与型号软排序、纯语义候选保护及单次八块上限。续轮均衡标题主体，并只对同文档后续重叠片段软降序，保留完整前文；没有修改原文或索引格式。实现、同向量对照结果及新长文未达项见 [retrieval-ranking-v2.md](retrieval-ranking-v2.md)。累计八千 token、索引有效性和范围隔离不变，额外模型重排默认关闭。

工具开启轮次暂存模型文本，确认该轮没有工具调用才发送；避免“我先检索”混入最终回答。普通聊天和禁用工具的最终轮次仍逐块输出，IPC 格式不变。引用 warnings 在诊断折叠区外显示。
