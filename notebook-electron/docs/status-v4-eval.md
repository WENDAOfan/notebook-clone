# 换新状态新题：预注册协议

先前 80 篇近名资料的失败题及其九次证据回放已用来诊断，**不得再当新验收题**。本题集 `eval/status-v4-cases.js` 在修改生产作答规则前固定：六份新的虚构短资料、六题，校准与留出各三题，分别覆盖“只有申请且缺少完成记录”“现场明确未完成”“交接明确完成”。站名相近，但文档内容各自独立；所有资料放进同一个临时笔记本，每题清空历史。

预先固定判分：缺少完成记录的题只能回答“文档没有完成记录，无法确认现场实际状态”，不能断言实际尚未完成；现场明确未实施的题应正常说未完成；签字交接明确完成的题应正常说已完成。三道留出题必须 3/3 状态判断正确且关键结论由本站引用支持，未知引用和跨站事实均为零。证据级 Recall@5 应为 3/3；索引和请求必须有效结束。数值仅属这个受控题集，不能覆盖 80 篇资料的未通过结论。

执行顺序：先 `node eval/production-cases.js --suite status-v4 --split all --prepare` 固定题集 SHA；再以**旧规则**只跑 `--split calibration --online --label before-v1`。核对校准结果后才允许修改 `answer-policy.js` 并补离线测试，然后只跑一次新留出组 `--split holdout --online --label after-v1`。若留出未达门槛，照实记录；不改题、不重跑挑最好一次。在线命令只向现有智谱 Embedding 和 DeepSeek 发送上述虚构文本，使用独立临时数据库与向量文件，不接触个人知识库。
